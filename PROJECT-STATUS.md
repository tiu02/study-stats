## Known Issues

- Existing sessions created before Phase 5 enhancements lack `color` and `status` fields. The UI falls back gracefully (indigo border, "Complete" badge), but editing an old session will add the new fields on save.
- Firestore security rules have not been redeployed since Phase 6/6B changes (added `assignmentId` to sessions, added `color`/`totalMinutesLogged` to assignments, tightened session subject size limit from 75 to 40 chars). Run `firebase deploy --only firestore:rules` before testing create/update in production.
- Material Icons loaded via Google Fonts CDN — requires internet connection. Icons will not render offline.
- Existing sessions with subjects longer than 40 characters will display correctly but editing such a session will enforce the new 40-character limit on save.
