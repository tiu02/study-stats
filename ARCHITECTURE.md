## Tech Stack

- Frontend: React 19 + Vite 7
- Routing: React Router v7
- Authentication: Firebase Auth (Email/Password)
- Database: Firebase Firestore
- Date Utilities: date-fns
- Icons: Material Symbols Outlined (Google Fonts CDN)
- Testing: Vitest + React Testing Library
- Deployment: Netlify (connected to GitHub)
- Serverless Functions: Netlify Functions v2 (ESM `export default` format)
- External APIs: YouTube Data API v3 (server-side via Netlify Function), ZenQuotes API (server-side via Netlify Function)

Uses `forwardRef` + `useImperativeHandle` to expose `forceStop()` (used by close-modal and conflict resolution). `vertical` prop switches to a centered column layout with a larger ring for the modal context. `autoStart` prop fires once on mount to auto-start the timer after a Stop & Start conflict resolution. Timestamp-based calculation: stores `startedAt` (Date.now()) and `accumulatedMs` in refs; remaining = `totalMs - (Date.now() - startedAt + accumulatedMs)` — immune to tab-throttling drift. SVG ring size is CSS-controlled (no hardcoded width/height attributes). `phaseTransitionRef` delays the break-phase transition 1.5s after work completes so the depleted ring is visible before resetting. On work cycle complete: toast fires only after `addSession` write succeeds; `sessionSaved` flag distinguishes `addSession` failure from `updateAssignment` failure in error messages. Browser Notification API permission requested on first start. `beforeunload` warning when running. Accepts `activeTimerId`/`onTimerStart`/`onTimerStop` props for single-timer coordination.

- `src/hooks/useFirestore.js` — Custom React hooks wrapping the Firestore service. Exports: `useSessions(uid)`, `useAssignments(uid)`, `usePomodoro(uid)`. Each returns data array, `loading`, `error`, mutation functions, and `refresh()`. Mutations return `true`/`false` for success/failure. Errors mapped to user-friendly messages via `friendlyError()` helper. `console.error` in `friendlyError` is gated behind `import.meta.env.DEV` — suppressed in production builds.
- `firestore.rules` — Firestore security rules. Denies all access by default. Per-collection rules under `users/{userId}` enforce `isOwner()` auth check, `hasAll`+`hasOnly` for required/allowed fields on create, `diff().affectedKeys().hasOnly()` on update with full field-level re-validation (type checks, size limits, enum validation). 40-char subject cap on both sessions and assignments, `subject.size() >= 1` enforced on both create and update, `createdAt == request.time` for server timestamp integrity. Dead pomodoro collection rules removed (timer writes to sessions/assignments via `addSession`/`updateAssignment`). Deployed to production.
- `index.html` — App shell. Loads Material Symbols Outlined from Google Fonts CDN for edit/delete/add icons.
- `public/_redirects` — Netlify SPA redirect rule. Sends all routes to `index.html` so React Router handles client-side routing and 404s.
- `vite.config.js` — Vite config with Vitest test configuration (jsdom environment, globals).
- `netlify.toml` — Netlify build config: `command = "npm run build"`, `publish = "dist"`, `functions directory = "netlify/functions"`.
- `netlify/functions/youtube-search.js` — Netlify Function v2. Accepts `?q=` query param; validates (empty reject, 100-char cap); calls YouTube Data API v3 search with `YOUTUBE_API_KEY` from `process.env`; `maxResults=6` for pool-based shuffle; decodes HTML entities (`&amp;`, `&quot;`, `&#39;`, `&lt;`, `&gt;`) in title and channelTitle before returning; returns `{ items: [{ videoId, title, channelTitle, thumbnail }] }`; maps 401→invalid key, 403→quota exceeded, network failure→502.
- `netlify/functions/quotes.js` — Netlify Function v2. Proxies ZenQuotes API (`zenquotes.io/api/quotes`) server-side to avoid CORS restrictions; no API key required; normalizes ZenQuotes `{ q, a }` format to `{ text, author }`; filters out `zenquotes.io` attribution entries; returns full normalized array with `Cache-Control: public, max-age=3600`.

## Data Model

All user data lives in subcollections under `users/{uid}`:

| Collection | Path | Fields |
|---|---|---|
| sessions | `users/{uid}/sessions/{id}` | `subject` (string), `duration` (number, minutes), `notes` (string), `date` (timestamp), `color` (string, hex), `status` (string: `complete` \| `in-progress` \| `incomplete`), `assignmentId` (string \| null — links Pomodoro-created sessions to parent assignment), `createdAt` (server timestamp) |
| assignments | `users/{uid}/assignments/{id}` | `title` (string), `subject` (string, 40-char max), `dueDate` (timestamp), `completed` (boolean), `color` (string, hex), `totalMinutesLogged` (number — incremented by Pomodoro on cycle complete), `createdAt` (server timestamp) |
| pomodoro | `users/{uid}/pomodoro/{id}` | `workMinutes` (number), `breakMinutes` (number), `completedAt` (server timestamp) — **unused**: Firestore rules for this collection were removed in Phase 8B; timer writes sessions via `addSession` instead. Service functions `logPomodoroSession`/`getPomodoroLogs` are dead code. |
