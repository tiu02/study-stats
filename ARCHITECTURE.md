## Tech Stack

- Frontend: React 19 + Vite 7
- Routing: React Router v7
- Authentication: Firebase Auth (Email/Password)
- Database: Firebase Firestore
- Date Utilities: date-fns
- Icons: Material Symbols Outlined (Google Fonts CDN)
- Testing: Vitest + React Testing Library
- Deployment: Netlify (connected to GitHub)

## Key Files

- `src/main.jsx` — Entry point. Wraps app in `BrowserRouter` > `AuthProvider`.
- `src/App.jsx` — React Router routes: `/` (public), `/login`, `/signup`, `/dashboard`, `/sessions`, `/assignments` (protected), `*` (404). Renders Navbar above all routes. `/pomodoro` route removed in Phase 7 — timer is accessed via a modal on the Assignments page.
- `src/App.css` — Landing page styles (indigo color scheme, feature cards with icons, responsive grid).
- `src/index.css` — Global base styles and resets (light theme, clean reset — Vite boilerplate removed).
- `src/firebase.js` — Initializes Firebase App, Auth, and Firestore. Exports: `app`, `auth`, `db`. Config values read from `VITE_`-prefixed env vars in `.env.local`.
- `src/context/AuthContext.jsx` — Auth provider using `onAuthStateChanged`. Exports `useAuth()` hook providing: `currentUser`, `loading`, `login()`, `signup()`, `logout()`.
- `src/components/Icons.jsx` — Shared SVG outline icon components (DashboardIcon, SessionsIcon, AssignmentsIcon, PomodoroIcon, ProfileIcon). Used by Navbar and Landing.
- `src/components/Modal.jsx` — Reusable modal overlay component. Focus trap (Tab/Shift+Tab cycles within modal), Escape key close, backdrop click close, `document.body.style.overflow = 'hidden'` while open. Accepts `ariaLabel`, `ariaDescribedBy`, `role`, `className` props. Used by Sessions and Assignments pages for add/edit/delete modals.
- `src/components/Modal.css` — Modal overlay styles: fixed full-screen backdrop (rgba black 0.4), centered content box (max-width 520px, scrollable), `modal-overlay-centered` class for mobile delete modal centering, mobile breakpoint shifts alignment to flex-start with top padding for tall forms.
- `src/components/AssignmentForm.jsx` — Reusable assignment form for add/edit. Fields: subject/class (text with datalist autocomplete, 40-char limit, auto-selects color from classMap when a known class is typed), color (7 urgency-safe presets — no red/amber/green — plus custom `<input type="color">` picker), title (assignment name, 200-char limit), due date (date picker). Accepts `classMap` prop (`{ [name]: color }` derived from existing assignments) for autocomplete + auto-color. Accepts `initialData` for edit/duplicate mode, `formId` for unique ARIA IDs, `formError` for Firestore errors. Same accessibility patterns as SessionForm (noValidate, aria-describedby, aria-invalid, double-submit protection).
- `src/components/AssignmentForm.css` — Assignment form styles: same layout patterns as SessionForm.css.
- `src/components/PomodoroTimer.jsx` — Pomodoro timer rendered inside a page-level modal in Assignments.jsx. Uses `forwardRef` + `useImperativeHandle` to expose `forceStop()` (used by close-modal and conflict resolution). `vertical` prop switches to a centered column layout with a larger ring for the modal context. `autoStart` prop fires once on mount to auto-start the timer after a Stop & Start conflict resolution. Timestamp-based calculation: stores `startedAt` (Date.now()) and `accumulatedMs` in refs; remaining = `totalMs - (Date.now() - startedAt + accumulatedMs)` — immune to tab-throttling drift. SVG ring size is CSS-controlled (no hardcoded width/height attributes). `phaseTransitionRef` delays the break-phase transition 1.5s after work completes so the depleted ring is visible before resetting. On work cycle complete: toast fires only after `addSession` write succeeds; `sessionSaved` flag distinguishes `addSession` failure from `updateAssignment` failure in error messages. Browser Notification API permission requested on first start. `beforeunload` warning when running. Accepts `activeTimerId`/`onTimerStart`/`onTimerStop` props for single-timer coordination.
- `src/components/PomodoroTimer.css` — Timer styles: default flex-row layout (ring left, config+controls right) for any inline use; `.pomodoro-vertical` override for modal context (flex-column, centered, 140px ring, 1.5rem time font, 48px buttons). SVG size controlled by `.pomodoro-ring-wrap` container. Three time-string size classes (MM:SS / H:MM:SS / HH:MM:SS). Compact number inputs with spin arrows hidden. Circular play/pause/reset buttons. Indigo phase label (green for break). Slide-in toast animation. Mobile flex-wrap on the default row layout.
- `src/components/Navbar.jsx` — Sticky navigation bar with logo, centered nav links with outline icons (logged in: Dashboard, Sessions, Assignments + Logout + profile icon; logged out: Log In, Sign Up). Hamburger menu on mobile, no hamburger when logged out. Pomodoro link removed in Phase 7.
- `src/components/Navbar.css` — Navbar styles: sticky positioning, hamburger toggle with animated open/close icon, centered desktop links, mobile dropdown with aligned icons, logged-out single-row layout, 44px min-height logout touch target.
- `src/components/SessionForm.jsx` — Reusable session form for add/edit. Fields: subject (text with datalist autocomplete from `classMap`, auto-selects color when a known class is typed, 40-char limit), color (7 urgency-safe presets — no red/amber/green — plus custom `<input type="color">` picker, same set as AssignmentForm), duration (hours + minutes side-by-side inputs), date (date picker), status (select: complete/in-progress/incomplete), notes (optional textarea). Inline validation, duration >24h triggers overlay warning modal, hard cap at 2 weeks. `editing = Boolean(initialData?.id)` correctly distinguishes edit vs. fresh/template data. Accepts `classMap` prop (`{ [name]: color }`) for autocomplete + auto-color, `initialData` for edit mode, `formId` for unique ARIA IDs, `formError` for Firestore errors.
- `src/components/SessionForm.css` — Session form styles: color swatch picker with selected ring and focus-visible indicator, `.session-form .color-custom` (higher specificity to override label display:block) with hidden `<input type="color">` and dashed circular swatch, `align-items: center` on swatches row, duration h/m field layout with unit labels, custom select dropdown arrow, field errors, light-gray cancel buttons, right-aligned action buttons, self-contained duration warning modal overlay (z-index 300, amber confirm button, focus trap), mobile 44px swatch/custom-swatch sizing, mobile 16px input font-size, mobile flex-equal-width form buttons.

Exports: `addSession()`, `getSessions()`, `updateSession()`, `deleteSession()`, `addAssignment()`, `getAssignments()`, `updateAssignment()`, `deleteAssignment()`, `logPomodoroSession()`, `getPomodoroLogs()`.
- `src/utils/format.js` — Shared display utilities. - `src/hooks/useFirestore.js` — Custom React hooks wrapping the Firestore service. Exports: `useSessions(uid)`, `useAssignments(uid)`, `usePomodoro(uid)`. Each returns data array, `loading`, `error`, mutation functions, and `refresh()`. Mutations return `true`/`false` for success/failure. Errors mapped to user-friendly messages via `friendlyError()` helper.
- `firestore.rules` — Firestore security rules. Denies all access by default. Per-collection rules under `users/{userId}` enforce `isOwner()` auth check, `hasAll`+`hasOnly` for required/allowed fields, type validation, size limits (40-char subject cap on both sessions and assignments), enum validation for session status, and `createdAt == request.time` for server timestamp integrity. Pomodoro docs are immutable (update denied). **Pending deploy** — run `firebase deploy --only firestore:rules` to push Phase 6/6B changes to production.
- `index.html` — App shell. Loads Material Symbols Outlined from Google Fonts CDN for edit/delete/add icons.
- `public/_redirects` — Netlify SPA redirect rule. Sends all routes to `index.html` so React Router handles client-side routing and 404s.
- `vite.config.js` — Vite config with Vitest test configuration (jsdom environment, globals).

## Data Model

All user data lives in subcollections under `users/{uid}`:

| Collection | Path | Fields |
|---|---|---|
| sessions | `users/{uid}/sessions/{id}` | `subject` (string), `duration` (number, minutes), `notes` (string), `date` (timestamp), `color` (string, hex), `status` (string: `complete` \| `in-progress` \| `incomplete`), `assignmentId` (string \| null — links Pomodoro-created sessions to parent assignment), `createdAt` (server timestamp) |
| assignments | `users/{uid}/assignments/{id}` | `title` (string), `subject` (string, 40-char max), `dueDate` (timestamp), `completed` (boolean), `color` (string, hex), `totalMinutesLogged` (number — incremented by Pomodoro on cycle complete), `createdAt` (server timestamp) |
| pomodoro | `users/{uid}/pomodoro/{id}` | `workMinutes` (number), `breakMinutes` (number), `completedAt` (server timestamp) |
